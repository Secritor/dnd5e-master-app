# MVP Scope

**Проект:** D&D инструмент для русскоязычного сообщества  
**Версия:** 0.1  
**Дата:** 2026-11-05

---

## Цель MVP

Сделать минимально рабочий продукт, которым мастер уже может пользоваться для ведения своих кампаний и персонажей. Всё остальное (публичный шеринг, темы, монетизация и т.д.) — вне scope.

---

## Что входит в MVP

### 1. Главная страница
- Базовая навигация
- Краткое описание продукта
- Переход к регистрации / входу
- Переход к основным разделам (после авторизации)

### 2. Авторизация и регистрация
- Регистрация по email + password
- Авторизация по email + password
- Авторизация через Яндекс
- Авторизация через ВКонтакте

### 3. Кампании
**Отдельная страница**

#### Отображение
- Карточки 400×500 px
- Column-расположение: 1/2 изображение, 1/2 информация
- Краткое описание на 2–3 предложения
- В футере карточки бейджи:
  - Рекомендуемый уровень игроков (например, «рек. ур. 12»)
  - Количество игроков
  - Сложность (легко / нормально / сложно)

#### Поиск и фильтрация
- Фильтры по бейджам:
  - Уровни: от 1 до 12 + опция «выше 12»
  - Количество игроков: от 1 до 8 + «больше»
  - Сложность: легко / нормально / сложно

#### Лайтбокс (детальная информация)
Открывается по клику на карточку.

Содержит:
- Тайтл (название кампании)
- Подробное описание на 4–5 предложений от мастера
- Блок рекомендаций мастера / личных комментариев (могут быть ссылки и источники)
- Табы сверху лайтбокса для перехода к подробной информации

#### Фазы кампании
- Информация о кампании делится на фазы (1, 2, … сколько мастер создаст)
- Каждая фаза:
  - Текст с описанием (подробные сюжетные рельсы или общие заметки)
  - Раскрывается аккордеоном (т.к. текст может быть длинным)
- Все текстовые поля (описание кампании, фазы, рекомендации мастера) используют **базовый rich-text редактор**

#### Базовый rich-text редактор (входит в MVP)
Используется во всех описаниях (кампании, фазы, персонажи, предметы, заклинания).

Возможности в первой фазе:
- Редактирование текста
- Выделение (жирный / выделенный)
- Подчёркивание
- Создание обычных ссылок
- Базовое форматирование в стиле простого Word

> Линкование на сущности из базы мастера (NPC / предметы с тултипами) и трекер боя переносятся на следующую фазу.

#### CRUD
- В заголовке лайтбокса кнопки редактирования и удаления
- **Удаление**: оверлей с предупреждением, необходимо ввести название кампании
- **Редактирование**: открывается новый лайтбокс для редактирования полей:
  - Текст фаз (через rich-text редактор)
  - Названия фаз
  - Обычные ссылки в тексте
- После сохранения: прогресс-индикатор → закрытие редактора → открытие просмотра с актуальными данными

### 4. Заметки
**Важно:** отдельной страницы «Заметки» нет.

Заметки реализуются как **виджет**, который можно встраивать в разные места:
- В описание персонажа
- В описание предмета / заклинания
- В кампанию
- В любые другие сущности, где нужно оставить короткий комментарий или акцент без редактирования всего текста

### 5. Персонажи
**Отдельная страница**

#### Отображение
- Два режима:
  - Карточки (300×200 px)
  - Таблица (сжатая информация без изображения)
- На карточке:
  - Имя
  - Изображение
  - В футере — краткая статистика (пока только бейдж уровня)
- Карточки кликабельны

#### Поиск и фильтрация
- Поиск по имени
- Фильтр по уровню

#### Лайтбокс (детальная информация)
Открывается по клику на карточку / строку таблицы.

Содержит:
- Характеристики
- Класс брони
- Инициатива
- Скорость
- Особенности класса и расы
- Ячейки заклинаний
- Уровень
- Снаряжение
- Мировоззрение
- Дополнительный блок заметок / описание мастера (виджет заметок)
- Список кампаний, в которых персонаж используется

#### CRUD
- Просмотр
- Редактирование
- Сохранение
- Удаление отдельных полей / блоков внутри лайтбокса
- Удаление персонажа целиком (с подтверждением)

### 6. Предметы
**Отдельная страница**

#### Отображение
- Два режима: карточки или таблица
- На карточках — бейджи, соответствующие фильтрам (оружие / броня / снаряжение / другое)

#### Поиск и фильтрация
- Поиск по названию (с debounce, т.к. запрос к базе)
- Фильтры по категории: оружие, броня, снаряжение и т.д.
- Пагинация:
  - Если карточек > 10 — появляется пагинация
  - Если строк в таблице > 40 — появляется пагинация

#### Лайтбокс (детальная информация)
Открывается по клику на карточку или строку таблицы.

Содержит:
- Заголовок (название предмета)
- Изображение / иконка (если есть)
- Описание предмета (rich-text редактор)
- Характеристики (сила, атака и т.д.)
- Эффекты (дополнительные заклинания, ячейки заклинаний, эффекты на персонажа)
- Заметки мастера
- В футере: в каких кампаниях и у каких персонажей используется

#### CRUD
- В шапке лайтбокса кнопки: Удалить и Редактировать
- **Удаление**: оверлей с подтверждением
- **Редактирование**: открывается новый лайтбокс с предзаполненными полями текущими данными предмета
- Валидация полей (запрещённые символы и т.п.)
- После сохранения: форма закрывается → лоадер → открытие просмотра с актуальными данными

### 7. Заклинания
**Отдельная страница**

#### Отображение
- Два режима: карточки или таблица

#### Поиск и фильтрация
- Поиск по названию (с debounce)
- Фильтры:
  - Уровень заклинания
  - Школа магии
- Пагинация:
  - Если карточек > 10 — появляется пагинация
  - Если строк в таблице > 40 — появляется пагинация

#### Лайтбокс (детальная информация)
Открывается по клику на карточку или строку таблицы.

Содержит:
- Заголовок (название заклинания)
- Изображение (если есть)
- Характеристики заклинания
- Ячейки, которые оно тратит
- Эффект, который производит
- Заметки мастера
- Внизу: у каких персонажей / в каких кампаниях используется

#### CRUD
- В шапке лайтбокса кнопки: Удалить и Редактировать
- **Удаление**: оверлей с подтверждением
- **Редактирование**: открывается новый лайтбокс с предзаполненными полями текущими данными заклинания
- Валидация полей (запрещённые символы и т.п.)
- После сохранения: форма закрывается → лоадер → открытие просмотра с актуальными данными

### 8. Кастомная UI-библиотека
Обязательная часть MVP. Компоненты должны быть готовы к последующей кастомизации (темы, рамки и т.д.).

**Компоненты, которые входят в библиотеку:**

- Карточки (разных размеров)
- Кнопки
- Заголовки
- Параграфы
- Инпуты
- Кнопки с дропдаунами
- Селекты
- Пейджеры
- Чекбоксы
- Лайтбоксы
- Text field
- Дивайдер
- Таблица
- Алерт
- Скелетон
- Прогресс
- Пагинация
- Табы
- Контейнеры
- Гриды

## Что **не** входит в MVP

- Публичный / общий пул контента
- Шаринг кампаний между пользователями
- Темы и декоративные рамки (кроме базовой реализации UI-библиотеки)
- Подписки и монетизация
- Рейтинги и форки
- Сложный блочный редактор заметок
- Real-time коллаборация
- Мобильная адаптация (кроме базовой работоспособности)
- **Трекер боя / инициативы** (учёт ХП, ячеек, ресурсов)
- **Hover-тултипы и линкование на сущности** из базы мастера (NPC / предметы с расширенной информацией)
- Цветовые маркеры с заметками на тексте фаз
