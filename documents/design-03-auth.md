# Экран «Вход мастера» — спецификация для реализации

Артборд макета: **Вход мастера (2 шага)**, 1440×900. Это не отдельный роут. Это модалка поверх текущей страницы. Код: `src/features/master-auth`. Сейчас её открывает главная; после оболочек из спецификаций главной и каталога её открывает публичная шапка.

Эта спецификация самодостаточна. Остальные `design-*.md` не читать.

## Контракт идентичности

Диалог при ширине 1440px совпадает с макетом: ширина, отступы, радиус, цвета, шрифты, порядок блоков, русский текст, оба шага.

Окно уже 900px — высота артборда, не минимальная высота приложения. Диалог по центру вьюпорта. Страница под ним прокручивается как раньше, сама модалка не растягивает документ до 900px.

Ховер ссылок внутри диалога: `#E6B676`. `:focus-visible` — `outline: 2px solid #D9A35B; outline-offset: 2px`. Кнопки в покое как ниже, отдельных ховеров макет не задаёт.

## Стек и границы

- CSS Modules в `features/master-auth`. Инлайн-стили не писать.
- Строки в `ru.ts` и `en.ts`.
- Слой `widgets` не создавать. Модалка остаётся фичей `master-auth` и по-прежнему экспортируется из её `index.ts`.
- Оболочка диалога — существующий `Modal` из `@/shared/ui`, если он умеет оверлей, Escape и фокус-ловушку. Внешний вид — по этой спецификации, не дефолт компонента. Если `Modal` навязывает другую ширину, фон или радиус, стили оверлея и панели переопределить модулем фичи, компонент не форкать.
- Реальных Яндекс ID, VK ID и Mail.ru нет. Кнопки провайдеров видимы и ничего не делают: ни `signIn`, ни переход, ни тост.
- `documents/Design System.md` не менять. Старые токены не удалять.

## Поведение сессии

Стартовый шаг при каждом открытии — «Вход в Мастерскую», не шаг кода и не старая форма с паролем.

«Получить код» не проверяет почту и не шлёт письмо. Любой клик переключает на шаг «Введите код». Поле почты можно оставить пустым.

«Изменить» на втором шаге возвращает на первый. Введённая почта сохраняется в состоянии модалки, пока она открыта.

«Войти» на втором шаге вызывает существующий `signIn()` из `useSessionStore` и закрывает модалку. Если модалка открыта не на `/master`, после входа перейти на `/master`. Код из шести цифр не проверять: кнопки «Войти» достаточно. Пустые клетки код не блокируют.

Закрытие: крестик, Escape, клик по оверлею. При следующем открытии снова шаг почты. Сессию крестик не создаёт.

Кнопки «Яндекс ID», «VK ID», «Mail.ru» — `type="button"` без обработчика эффекта.

Старые экраны логина и регистрации с паролем из модалки убрать. Отдельный роут для них не добавлять. Легаси-страницу `pages/master-auth` не подключать к роутеру и не редизайнить: она и раньше была вне роутера.

Ссылку «Регистрация» не показывать. В макете новый аккаунт создаётся тем же входом; для мока это тот же `signIn()`.

## Подложка

Макет рисует серую схему главной на `opacity: 0.5` и сверху оверлей. Живое приложение так не делать: под модалкой остаётся настоящая текущая страница.

Оверлей: `background: rgba(12, 10, 8, 0.72)`, на весь вьюпорт, flex, `align-items: center`, `justify-content: center`, `padding: 24px`, `box-sizing: border-box`. Страницу под оверлеем не заменять скелетоном.

## Диалог

`role="dialog"`, `aria-modal="true"`, `aria-labelledby` на заголовок текущего шага.

Панель: `position: relative`, ширина 100%, `max-width: 440px`, `box-sizing: border-box`, `padding: 40px 32px 32px`, radius 16px, фон `#302A22`, рамка `1px solid #3D362C`, column, `gap: 24px`. Цвет текста `#EDE4D6`, шрифт Inter 16px / 24px.

Крестик: `position: absolute; top: 12px; right: 12px`, 44×44, без рамки и фона, flex по центру, `aria-label` «Закрыть». Иконка 18×18, `viewBox="0 0 18 18"`, stroke `#A89C8A`, `stroke-width="1.75"`:

```svg
<path d="m4 4 10 10M14 4 4 14" />
```

Крестик есть на обоих шагах.

## Шаг 1. Почта

Column, `gap: 24px`.

Заголовочный блок, column, `gap: 8px`:

- `h2` «Вход в Мастерскую»: margin 0, Cormorant Garamond, weight 600, 32px / 40px, цвет `#EDE4D6`
- подпись «Новый аккаунт создастся автоматически при первом входе»: margin 0, 14px / 20px, цвет `#A89C8A`

Три кнопки провайдеров, column, `gap: 12px`. Каждая: высота 48px, radius 8px, рамка `1px solid #3D362C`, фон `#26221C`, цвет `#EDE4D6`, `font: 500 15px Inter`, flex, по центру, `gap: 12px`.

Слева у каждой значок-квадрат 24×24, radius 6px, фон `#3D362C`, цвет `#EDE4D6`, flex по центру:

- «Я» — 12px, weight 600. Кнопка: «Войти через Яндекс ID»
- «VK» — 10px, weight 600. Кнопка: «Войти через VK ID»
- «@» — 13px, weight 600. Кнопка: «Войти через Mail.ru»

Значок `aria-hidden`. Логотипы брендов не рисовать: в макете именно буквы на квадрате.

Разделитель «или»: flex, `align-items: center`, `gap: 16px`, 13px, цвет `#A89C8A`, `aria-hidden="true"`. Слева и справа линия `flex-grow: 1`, высота 1px, фон `#3D362C`. Слово «или» между ними.

Блок почты, column, `gap: 12px`.

`label`, column, `gap: 8px`, 14px / 20px, weight 500, цвет `#EDE4D6`. Текст лейбла: «Электронная почта».

Инпут `type="email"`, placeholder «name@mail.ru»: высота 48px, `padding: 0 16px`, radius 8px, рамка `1px solid #3D362C`, фон `#26221C`, цвет `#EDE4D6`, `font: 400 16px Inter`. Автозаполнение браузера не запрещать.

Кнопка «Получить код»: высота 48px, radius 8px, без рамки, фон `#D9A35B`, цвет `#1C1915`, `font: 600 16px Inter`, на всю ширину.

Низ: margin 0, 12px / 18px, цвет `#A89C8A`, `text-align: center`. Текст: «Продолжая, вы принимаете соглашение и политику конфиденциальности». Слова «соглашение» и «политику конфиденциальности» — ссылки цвета `#D9A35B` без подчёркивания. Обе ведут в никуда (`href` нет, это кнопки или ссылки с `preventDefault`). Страницы соглашения не создавать.

## Шаг 2. Код

Column, `gap: 24px`. Заголовок шага тоже `h2`, тот же размер: Cormorant Garamond, weight 600, 32px / 40px. Текст: «Введите код». `aria-labelledby` диалога переключается на этот заголовок.

Подпись: margin 0, 14px / 20px, `#A89C8A`. Текст: «Мы отправили 6-значный код на {почта}.» Если почта пустая, подставить «name@mail.ru» — так звучит макет, когда пример не введён. Если пользователь что-то ввёл, показать это, не пример.

Рядом слово «Изменить»: без фона и рамки, padding 0, цвет `#D9A35B`, `font: 500 14px Inter`. Оно в той же строке, что подпись, не отдельным абзацем.

Цифры `4` и `7`, которые стоят в макете в первых двух клетках, — черновик превью, не начальное состояние. Все шесть полей при входе на шаг пустые.

`fieldset`: margin 0, padding 0, без рамки, grid `repeat(6, minmax(0, 1fr))`, `gap: 8px`.

`legend` скрыт так же, как подпись поиска: «Код из письма».

Каждая клетка: `input type="text"`, `inputmode="numeric"`, `maxlength="1"`, высота 56px, `min-width: 0`, `text-align: center`, radius 8px, рамка `1px solid #3D362C`, фон `#26221C`, цвет `#EDE4D6`, `font: 600 22px Inter`. `aria-label`: «Цифра 1» … «Цифра 6».

Клетка с фокусом: рамка `2px solid #D9A35B` вместо 1px `#3D362C`. Это и есть вид фокуса с макета (третья клетка в превью). Плюс общий `:focus-visible` не дублировать вторым кольцом: для этих шести полей фокус — смена рамки, outline убрать (`outline: none` только на `:focus-visible` этих полей).

Ввод: оставить одну цифру, остальное выкинуть. После цифры фокус в следующую пустую клетку. Backspace на пустой клетке переносит фокус на предыдущую. Вставка шести цифр раскладывает их по клеткам. Этого в скрипте макета нет, но без этого ряд из шести `maxlength="1"` не работает как код. Таймер не запускать.

Кнопка «Войти»: высота 48px, radius 8px, фон `#D9A35B`, цвет `#1C1915`, weight 600, flex по центру, на всю ширину. Это переход в мастерскую, не `submit` несуществующей формы с паролем.

Под ней по центру: margin 0, 14px / 20px, `#A89C8A`. Текст строго «Отправить код повторно через 0:59». Строка статичная. Интервал, кнопку «отправить снова» и смену секунд не делать.

## Чего не делать

- Не рисовать скелетон главной под оверлеем.
- Не подключать OAuth и не имитировать успешный вход по кнопкам провайдеров.
- Не валидировать почту и код, не показывать ошибки полей: в макете их нет.
- Не запускать таймер 0:59.
- Не оставлять в модалке поля пароля, подтверждение пароля и экран «Учётная запись создана».
- Не делать отдельную страницу `/auth`.

## Приёмка

- Из шапки «Войти» диалог по центру, максимум 440px, фон `#302A22`, крестик 44×44.
- Подложка `rgba(12, 10, 8, 0.72)`, под ней видна текущая страница, не серые полоски.
- Шаг 1: заголовок 32px, три кнопки с «Я» / «VK» / «@», слово «или», поле почты, золотая «Получить код», юридическая строка.
- Провайдеры не создают сессию.
- «Получить код» даже с пустой почтой открывает шаг 2. Подпись содержит «name@mail.ru». С введённой почтой подпись содержит её.
- Шесть пустых клеток. Фокус меняет рамку на 2px `#D9A35B`.
- «Изменить» возвращает на шаг 1 с той же почтой.
- «Войти» ставит `isAuthenticated` и открывает `/master`.
- Строка «Отправить код повторно через 0:59» не тикает.
- Escape и крестик закрывают модалку без сессии.
- Повторное открытие снова показывает шаг почты.

Проверка: `npm run build:check`. Показать вывод. `docs/` вне `develop` убрать `npm run clean`.
