# Структура проекта `dnd-game-tool`

> Навигационная карта. Обновлено с учётом новой дизайн-системы и MVP Scope.  
> Последнее обновление: 2026-11-06.

---

## 1. Что это

SPA-инструмент для D&D (пространство мастера, кампании, персонажи, предметы, заклинания).  
Бэкенда пока нет — моки. Деплой — статика на GitHub Pages.

**Стек:**
- React 19 + TypeScript + Vite
- FSD v2.1
- TanStack Query, Zustand, react-hook-form + Zod
- i18n (ru/en)
- **Своя UI-библиотека** (`shared/ui`) + CSS Modules
- **Дизайн-система:** Soft Dark Fantasy (Ember/Honey акценты, Cormorant Garamond + Inter)

---

## 2. Слои FSD

Без изменений: `app → pages → features → shared`.  
`widgets` и `entities` пока не используются.

---

## 3. Ключевые изменения по сравнению со старой структурой

### Стили и тема
- Токены в `app/styles/tokens.css` будут обновлены под новую палитру:
  - Charcoal `#1A1A1A`, Soot `#2C2C2E`, Ember `#E07A3D`, Honey `#F5C16C` и др.
- Шрифты: Cormorant Garamond (заголовки) + Inter (текст)
- Тема остаётся тёмной

### UI-библиотека (`shared/ui`)
Планируется расширение до компонентов из MVP Scope:
- Button, TextField, Card, Modal/Lightbox
- Table, Chip/Badge, Skeleton, Pagination
- Tabs, Select, Checkbox и др.
- Все компоненты используют токены дизайн-системы

### Страницы (целевые)
- `/` — выбор режима
- `/master` — хаб
- `/master/campaigns` (или аналог) — кампании с лайтбоксом и фазами
- `/master/characters` — персонажи
- `/master/items` — предметы
- `/master/spells` — заклинания
